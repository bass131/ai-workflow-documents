**AgentDeck은 AI와의 대화, 코드 읽기, 변경 사항 검토, Git 작업을 한 화면에서 다루는 데스크톱 개발 도구다.** 여러 도구를 오가는 대신, 개발자가 변경을 요청하고 그 결과를 확인할 수 있게 한다.

## 어떤 일을 하는 프로그램인가

- **에이전트와 작업한다:** 프로젝트 폴더를 열고 코딩을 요청하며, 진행 상황과 도구 실행 내용을 확인한다.
- **결과를 검토한다:** 파일을 읽고 변경 전후를 비교하는 diff 화면에서 반영할 내용을 판단한다.
- **개발 작업을 관리한다:** Git 이력과 브랜치를 확인하고, 대화 세션이나 에이전트 패널을 나누어 사용한다.

앱은 Electron·React·TypeScript로 구성되어 있으며, 에이전트 실행에는 Claude Agent SDK를 연결해 사용한다.

| 구분 | 역할 |

| **워크플로** | **설계하고 시험하는 목표 기반 작업 방식.** 목표, 검증 조건, 작업을 이어받는 데 필요한 기록을 정의한다. |
| **이 위키** | **방법과 근거를 설명하는 문서.** 개념, 설계 선택, AgentDeck 같은 프로젝트에서 확인한 사례를 정리한다. |

[AgentDeck에서 배운 것](../../experiments/agentdeck/)은 이 프로젝트의 개발 과정에서 사용한 검사 스크립트를 다룬다. 해당 실험은 프로그램 전체 기능을 평가한 결과가 아니다.

## 구현된 부분과 제안하는 부분

**기존 구현:** 데스크톱 앱과 Claude Agent SDK 연결.

**추가 제안:** Codex App Server 연결과 목표·검증·재개를 공통으로 관리하는 프로그램. 구체적인 방향과 한계는 [설계 결정](../../design/decisions/)에서 설명한다. 문서 사이트 자체가 AgentDeck을 실행하거나 에이전트를 제어하지는 않는다.

*구현 상태는 2026년 9월 18일 프로젝트 README와 소스를 기준으로 확인했다. 이번 문서 작성에서 앱 실행 검사를 새로 수행하지는 않았다.*
